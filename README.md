# Análise de Investimentos e Vendas
Este projeto tem como objetivo analisar a relação entre investimentos realizados em diferentes canais de marketing e o volume de vendas obtido. A partir da análise dos dados, buscando identificar quais tipos de investimento apresentam maior relação com as vendas e utilizar técnicas de regressão linear para avaliar e estimar esse comportamento.

## Objetivos


- Analisar a relação entre investimentos e vendas;
- Identificar quais variáveis possuem maior influência sobre as vendas;
- Explorar e visualizar os dados;
- Realizar tratamento e preparação dos dados;
- Desenvolver um modelo de regressão linear;
- Avaliar o desempenho do modelo;
- Utilizar o modelo para realizar previsões.

## O que foi analisado

Análise exploratória

- Quantidade de registros;
- Tipos de dados;
- Valores ausentes;
- Estatísticas descritivas;
- Distribuição das variáveis;
- Relação entre investimentos e vendas;
- Correlação entre as variáveis.

## Tratamento dos dados

- Identificação de valores ausentes;
- Verificação de valores duplicados;
- Conversão dos tipos de dados;
- Seleção das variáveis utilizadas no modelo.

## Modelagem

- Separação entre variável independente e variável alvo;
- Treinamento do modelo de regressão linear;
- Geração de previsões;
- Avaliação do modelo utilizando métricas apropriadas.

## Tecnologias utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- VS Code
- Git e GitHub

## Resultados

Com a análise foi possível identificar uma relação entre os investimentos realizados e o volume de vendas.

O modelo de regressão linear apresentou:

- R²: 0.9647
- MAE: 8.7622
- RMSE: 12.2471

Os resultados indicam que para um investimento de R$ 25 mil, a previsão de vendas é: 122.46 mil unidades.


## Conclusão

A análise permitiu compreender como os investimentos estão relacionados ao volume de vendas e demonstrou a aplicação de técnicas de Ciência de Dados para apoiar decisões relacionadas à alocação de investimentos. O modelo desenvolvido também possibilitou realizar estimativas de vendas a partir dos valores investidos.
